# Awesome Norm

[简体中文](README.zh-CN.md)

A curated list of applications built with [Norm](https://github.com/normlanguage/Norm) and high-level libraries intended directly for application development. Low-level bindings, technical adapters, toolchains and distribution infrastructure are outside this list's scope.

## Applications

- [Gait](https://github.com/w0fv1/Gait) — A stateless Norm CLI agent with Git tools and OpenAI-compatible model APIs.
- [Gpt-Copilot](https://github.com/w0fv1/Gpt-Copilot) — A native Windows desktop companion for Codex and ChatGPT. Private repository; access required.
- [Local API WebSocket Proxy](https://github.com/w0fv1/Local-API-WebSocket-Proxy) — A native Windows desktop proxy for accessing multiple local HTTP APIs and WebSockets through a WebSocket relay.

## UI

- [ui](https://github.com/normlanguage/ui) — Component, state and reconciliation framework for declarative application interfaces.
- [ui.fx.kit](https://github.com/normlanguage/ui.fx.kit) — JavaFX controls for declarative Norm desktop applications.
- [ui.web](https://github.com/normlanguage/ui.web) — Vaadin-backed browser applications using Norm UI components, state, layouts and themes.

## Web

- [micronaut-web](https://github.com/normlanguage/micronaut-web) — Composition module for Micronaut HTTP applications, with typed configuration and application lifecycle.

## AI

- [openai](https://github.com/normlanguage/openai) — OpenAI-compatible Responses and Chat Completions client with streaming output and function tools.

## Persistence

- [orm](https://github.com/normlanguage/orm) — Application-facing persistence API with entity mapping, repositories, typed queries and pagination.

Recommend projects within this scope by opening a pull request with a link and brief description.
