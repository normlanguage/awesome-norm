# Awesome Norm

[English](README.md)

收录基于 [Norm](https://github.com/normlanguage/Norm) 构建的应用与生态项目。

## 应用

- [Gait](https://github.com/w0fv1/Gait) — 无状态 Norm 命令行 Agent，集成 Git 工具和兼容 OpenAI 的模型 API。
- [Gpt-Copilot](https://github.com/w0fv1/Gpt-Copilot) — Windows 原生桌面 Codex / ChatGPT 辅助工具。私有仓库，需要访问权限。
- [Local API WebSocket Proxy](https://github.com/w0fv1/Local-API-WebSocket-Proxy) — Windows 原生桌面代理，通过 WebSocket 中继远程访问多个本地 HTTP API 和 WebSocket。

- [Norm-Skill](https://github.com/normlanguage/Norm-Skill) — 编写和维护 Norm 应用的参考驱动技能。
