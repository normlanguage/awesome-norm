# Awesome Norm

[English](README.md)

收录基于 [Norm](https://github.com/normlanguage/Norm) 构建的应用软件，以及直接面向应用开发的高层库。不收录底层绑定、技术适配器、工具链或发行基础设施。

## 应用

- [Gait](https://github.com/w0fv1/Gait) — 无状态 Norm 命令行 Agent，集成 Git 工具和兼容 OpenAI 的模型 API。
- [Gpt-Copilot](https://github.com/w0fv1/Gpt-Copilot) — Windows 原生桌面 Codex / ChatGPT 辅助工具。私有仓库，需要访问权限。
- [Local API WebSocket Proxy](https://github.com/w0fv1/Local-API-WebSocket-Proxy) — Windows 原生桌面代理，通过 WebSocket 中继远程访问多个本地 HTTP API 和 WebSocket。

## UI

- [ui](https://github.com/normlanguage/ui) — 用于声明式应用界面的组件、状态和协调框架。
- [ui.desktop.kit](https://github.com/normlanguage/ui.desktop.kit) — 用于声明式 Norm 桌面应用的 JavaFX 控件库。
- [ui.web](https://github.com/normlanguage/ui.web) — 基于 Vaadin 构建浏览器应用，复用 Norm UI 的组件、状态、布局与主题。

## Web

- [micronaut-web](https://github.com/normlanguage/micronaut-web) — 用于构建 Micronaut HTTP 应用的组合模块，提供类型化配置和应用生命周期。

## AI

- [openai](https://github.com/normlanguage/openai) — 兼容 OpenAI Responses 与 Chat Completions 的客户端，支持流式输出和函数工具。

## 持久化

- [orm](https://github.com/normlanguage/orm) — 面向应用开发的持久化 API，提供实体映射、Repository、类型化查询和分页。

欢迎通过 Pull Request 推荐符合收录范围的项目，附上项目链接和简短介绍。
